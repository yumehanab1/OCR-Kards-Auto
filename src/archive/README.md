# `src/archive/`

这里保存早期的一次性探针、诊断脚本和卡库抓取实验。它们只用于追溯历史，**不属于运行时链路**：当前代码不会 import 这个目录，发布包也不依赖它们。

使用这些脚本前要先检查路径和依赖。部分脚本面向旧版目录布局，可能含有旧的截图路径、旧的模块入口或只适用于某次实机排查的假设；不要把它们当作当前功能的验证入口。

新的测试、探针和标定工具放在 `dev/`，新的运行时模块放在 `src/` 根目录并按现有导入约定接入。若要恢复这里的某个实验，先复制到开发工具侧，修正仓库根路径和输出目录，再补离线验证，不要直接让运行时依赖 `src/archive/`。
