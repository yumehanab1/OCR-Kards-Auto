# KARDS Android 0.2.1

独立Android项目，包名`com.kards.mobilert`，versionCode109，最低Android11/API30，支持arm64-v8a和x86_64。使用简体中文游戏界面；当前验证的游戏版本为KARDS1.60.27292/code2703。

构建、签名与内置引擎验证见[上级源码说明](../README.md)。安装及功能说明见[手机版说明](../../README.md)。本项目不需要PC程序参与运行，开发测试使用ADB与设备回放。

主界面提供休闲/排位、有限局数或0无限，以及从菜单开始或接管当前对局。右侧悬浮状态条展示阶段和启停；展开保持运行，停止由用户点击。原图用于识别和后验，JPEG用于复盘；新证据采用350MiB预算，活动原图受保护。
