# KARDS Android 0.2.2

独立 Android 项目，正式版本为 `0.2.2 / versionCode 141`，包名 `com.kards.mobilert`，最低 Android 11/API30，支持 arm64-v8a 和 x86_64。

正式 APK 已完成构建、签名与内容检查，已在模拟器覆盖安装；设备组件检查结果见[公开验证报告](../../../docs/reports/mobile/APK_0.2.2_RELEASE.md)。[构建、签名与内置引擎检查](../README.md)和[安装使用](../../README.md)分别说明开发环境与用户设置。运行库和模型随 APK 提供，运行时无需 PC 程序或另装 Python。

游戏使用简体中文；画质不限，内容比例设为“原生”，UI 比例调为 1。

主界面提供休闲/排位、有限局数或 `0` 无限，可从菜单开始或接管当前对局。右侧悬浮状态条展示阶段并支持手动启停，展开保持运行。每步按攻击、移动、部署选择。

0.2.2 改善当前文字控件定位、16:9/宽屏适配、登录弹窗、对手换牌等待及重复识别开销。原图用于识别和后验，JPEG 用于复盘；新证据采用 350MiB 预算，活动原图受保护，旧历史不自动迁移清理。

开发验证来自 code140 模拟器十局和 code139 手机五局，正式 code141 的验证单独记录。识别仍为 OCR、模板、颜色和几何混合方案；其他设备、出牌后选目标和额外浮窗黑帧问题的范围见发布报告。
