## 附:怎么读这张表

* **费用**来自 `card_db`,是打出去要花的 kredits;引擎按它跟屏幕上的费用读数对账。
* **出处**是用户给规格时的编号(`A#行号` = `order_cards_A.md` 的文件行号;`B#序号` = `order_cards_review.md` B 表那一节的编号;`需要目标#N` = 「需要目标」那一节里的编号),用来回溯原始规格。
* 这份表**不是**『能不能付得起』的判据 —— 那要看当回合的费用,由引擎现算。
