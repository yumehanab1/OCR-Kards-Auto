# PC 0.2.3 发布

日期：2026-10-17。系统：runtime-test / 7A77-760D。

## 内容与实测

本版包含`b7222eb`的橙色费用、主牌识别、天气二次复核及阶段调度修订，保留传统策略开关。详细根因、真实帧回放与实机结果见[耗时修订报告](2026-10-17-speed-iteration.md)。

最终引擎在KARDS 1.61.2.7589、Windows PC、1280×720、便携Python 3.14.7完成一局线上休闲：13回合中位24.04秒、最长35.15秒，12次主动结束与1次胜利结束，无本局已确认的自动超时。费用拒识0次，确认出牌15张，天气二次复核1.599秒。8费新增模板只验证了真实帧回放，最终对局未遇到；0/9及两位费用仍缺样。

本次发版仅修改版本、更新源和说明，未再次修改已测引擎。GUI源码及内置更新器未变，复用已验证的冻结面板。发布门禁覆盖贡献指南五项、beta版本、备用附件和安装专项，以及空目录解压逐文件SHA-256、便携导入和冻结面板自检。

## beta迁移

已安装的0.2.2_beta固定检查自己的tag，且拒绝不匹配的远端标签。为兼容这些面板，beta页保留原tag、预发布属性及配套附件名，提供同版本的通道迁移构建：从原正式发布的beta完整包生成，只修改`config/app_version.json`的`update_url`到正式latest，重算完整清单和build标识，版本仍是0.2.2_beta。

用户先应用一次同版迁移，重启后再次检测安装0.2.3。两步分别校验配套manifest、文件大小和SHA-256，配置与安装清单的版本始终一致。旧beta标签对应源码不移动；迁移构建的唯一源码配置覆盖在本节说明。0.2.3完整包直接使用正式更新源。

发布验证使用原beta包中的更新器，在临时目录按真实ZIP完整走两步准备、安装，并核对本机配置/学习数据保护和最终版本、manifest一致。另检查实际远端API、限流备用附件、公开清单和分段成员下载。

## 构建与独立维护线

PC包由发布提交的Git跟踪文件构建，额外加入已验证的便携Python和冻结面板，不携带本机未提交的学习数据、日志、截图、交接文件或mobile目录。精确提交、包SHA-256和清单SHA-256登记在GitHub Release构建栏；本机验证证据及交接记录另存。

手机版源码入口与0.2.3页Mobile / Android说明位置保留。本次不构建APK；现有0.2.2手机版及其附件保留在原页。
