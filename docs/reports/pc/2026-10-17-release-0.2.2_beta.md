# PC 0.2.2_beta 发布验证（2026-10-17）

系统runtime-test / 7A77-760D。本版为独立预发布版，标签`v0.2.2_beta`，版本配置`0.2.2_beta`；具体源码提交由配套manifest的build.commit记录。
正式版0.2.2的标签、发布页、PC附件和手机版APK保持原样。

## 本版内容

- 面板新增可保存的“传统策略”，默认关闭。勾选并停止后重新开始时，绕过橙色筛选、费用组合和新增同点重悬停，使用传统布局/记忆/坐标扫描及出牌流程。
- 传统模式剩余1费仍能找牌，手牌不少于5张时最多成功出3张。保留零费不盲扫、12秒协作扫描截止、天气分版、选牌、守护及输入保护。
- beta版本与正式版可区分比较；更新器支持带`_beta`的PC附件及配套manifest。
- beta配置指向本beta的修订检查地址。默认正式更新源只选择正式版本；已安装的旧更新器无法通过本包远程改写，首次使用beta应直接下载完整测试包。

详细行为与既有耗时证据见[传统策略记录](2026-10-17-classic-strategy.md)。本版没有新增自动对局，游戏内版本未重新核实；不以离线通过声称回合超时已根治。

## 验证范围

- 传统策略9项、GUI设置持久化与CLI参数、基础五项、橙色首张、待修边界及桥接回归通过。
- 完整回合回归在本次最后一项引擎修改后输出ALL CASES PASSED；发版阶段只补beta兼容，不再改引擎。
- 5张历史PC悬停图两种模式分类一致：三张1费单位、旋风身份及效果正确；一张旧骤雨裁图两边都拒识。该回放没有游戏输入或指纹落盘。
- beta兼容9项通过，覆盖版本比较、公开附件回退、正式订阅过滤、PC包与清单配套及临时目录实际安装；更新检查、8项备用源及安装12项回归通过。重新构建的冻结面板确认传统策略、beta版本排序及beta附件解析标记均有效，版本和更新源均指向本beta。
- 发布包需经空目录解压、全部文件SHA256、1646条卡库、天气/费用模板、便携Python导入及冻结面板自检；最终文件哈希以Release清单为准。

## 下载与使用

[0.2.2_beta预发布页](https://github.com/yumehanab1/OCR-Kards-Auto/releases/tag/v0.2.2_beta)

PC包为`kards-auto_v0.2.2_beta_x86_64.zip`，配套`kards-auto_v0.2.2_beta_x86_64.manifest.json`。
首次测试请解压到新目录，打开面板勾选“传统策略”后运行；选项会保存，下次启动恢复，不会自动开局。
本beta只发布PC。手机版保留[源码入口](../../../mobile/source/README.md)及[正式版0.2.2下载](https://github.com/yumehanab1/OCR-Kards-Auto/releases/tag/v0.2.2)，beta页可供其独立维护线后续补充说明。
