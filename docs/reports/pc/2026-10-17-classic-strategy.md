# PC 传统策略切换（2026-10-17）

## 范围

系统runtime-test / 7A77-760D，功能开发基线`337e7ca051c054fc1c8e77f577e8dab57403049d`。本功能随0.2.2_beta预发布，构建提交以配套manifest记录为准。

用户反馈部分对局回合拖延，并确认需要橙色筛选加入前的传统流程，连橙色筛选和凑费也绕过。
正式v0.2.1标签`20051b0`已包含橙色扫描及费用组合，不能把本功能称为精确恢复该版本。

## 使用

面板勾选“传统策略”，停止后重新开始自动对局生效。默认关闭，选项自动保存在本机`config/gui_options.json`。
命令行对应`--classic-strategy`；参数由Controller传给TurnEngine及其扫描器，本次运行固定，不改全局环境变量。

| 行为 | 当前策略 | 传统策略 |
|---|---|---|
| 手牌入口 | 橙色候选首张扫描 | 测扇形边缘、布局/手牌记忆探针 |
| 橙色费用模板、身份缓存、放大费用补查 | 使用 | 绕过；直接调用橙色扫描入口也拒绝 |
| 运行时凑费 | 当前版已移除 | 不启用 |
| 首次悬停身份与费用均未读出 | 允许同点重悬停一次 | 跳过该次重试 |
| 坐标表/全量扫描 | 不从橙色失败回退 | 沿用传统回退，费用未知全量扫描每回合最多一次 |
| 剩余1费 | 可继续找牌 | 可继续找牌，避免恢复旧的低于2费直接收手 |
| 大手牌收手 | 默认橙色路径无此上限 | 手中不少于5张时，成功出牌达到3张收手；失败不计数 |
| 场上行动 | 先攻击、再移动、最后出牌 | 同顺序，使用共同的动作模块 |

最新卡库、指令权限、天气分版、连续选牌、守护、行动后战场刷新、失败退费及连续失败停手继续共用。
两种模式均保留零费不盲扫和传统扫描的12秒共享协作截止。截止只禁止后续探针，在途OCR和扫描后的面板采样可继续，因此不是整回合硬时限。

桌面现存主日志最新到2026-10-16 15:14，不能作为2026-10-17用户反馈的直接复现。

这些记录说明慢识别可能超过协作截止，不能直接证明所有用户回合超时具有同一原因。
