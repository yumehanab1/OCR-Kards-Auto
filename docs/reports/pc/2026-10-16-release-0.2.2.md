# PC 0.2.2 发布验证（2026-10-16）

测试系统：runtime-test / 7A77-760D。PC版本0.2.2，构建来源由配套manifest的build.commit记录。

## 本版改动

- 面板界面桥接只公开七个操作方法，避免启动时递归访问原生窗口无障碍属性而造成整个窗口无响应。
- 日志展示最多读取128KiB/400行，限制超长行显示；缓存未变日志并串行轮询。
  超过8MiB的日志在下次启动时归档保留，独立查看器支持追加、截短和轮换。
- 默认仅识别橙色手牌，单次找到第一张允许出牌的候选即停；出牌后重新扫描继续出牌。
  取消运行时凑费组合，不设每回合一张限制，也不承诺用完费用。
- 零预算不进入全手牌或盲扫；实际零费牌仍需橙色候选和费用确认。
- 左侧放大牌的费用区域在原区域无候选时补查同一帧，修复部分1费牌漏识；原费用/颜色门槛保留。
- 费用模板预处理缓存，增加扫描各阶段耗时及拒识读数记录。

## 验证范围

- gui、actions、update_check、orders、dismiss基础回归，以及桥接、长日志、橙色首张、
  橙色手牌、待修边界、增量安装专项通过。完整回合状态机在最后一次引擎改动后通过。
- 真实PC截图离线回放：三张左侧1费悬停图通过费用校验；191张旧拖牌帧保持原163个候选，
  原无候选帧补回12个可信费用。另有60张旧帧费用模板A/B，识别与分数一致。
- 面板修复在桌面实际副本验证两次启动、筛选按钮、窗口拖动及关闭重开。
  长日志隔离面板使用128MiB历史日志及模拟子进程验证，不向游戏输入。
- 发布包需通过ZIP自检、空目录全文件哈希核对、便携Python导入与解压面板自检后发布。

本版没有新增自动对局，游戏版本未重新核实。左侧费用区域修复仍需修复后游戏内确认；
其他系统/WebView2版本、其余天气版本及部分攻击后验路径沿用已有待测范围。
截图回放和模拟进程结果不作为新实机整局通过结论。
