## 功能与适用范围

- 休闲/排位、有限局数或0无限；从菜单开始或接管当前局；行动后部署。
- 右侧悬浮条显示状态/阶段/计数并手动启停；展开继续运行，截图/输入临时隐藏。
- 原图继续用于识别及后验，复盘证据保存原尺寸JPEG78，等待帧只保留文字/JSON。schema2新证据使用350MiB预算，按最旧非活动局整体淘汰，另设7天/100局上限；活动原图保护，不能腾出空间时停止。旧版本历史、调试完整留存和其他缓存不自动迁移清理，写入与活动帧还需要暂存空间。
- 比例判据保留16:9，并支持18:9/19:9/20:9范围内的横屏，保比例识别与源坐标恢复；本维护线最新整局实测为2772×1240宽屏。16:9得到上述保存帧回归，未跑新版16:9完整局。
