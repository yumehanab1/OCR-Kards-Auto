## 相对 0.2.2 的改进

- Android 11—13 增加可手动启用的 MediaProjection 兼容截图通道，供系统无障碍截图黑屏时使用。授权必须由用户在系统弹窗亲自确认，取消不会启动辅助；进程重启或撤销授权后需要重新授权。Android 14 及以上继续使用游戏窗口截图。
- 黑帧及不完整透明帧在进入识别前拒绝；不再把这些图当成普通“画面未知”。不完整帧、黑帧和临时窗口错误共用最多三次新鲜重采，含首次最多四次采集。每次清空旧帧，重采期间没有触控，取消和原总预算仍优先；持续异常仍停止。
- 浮窗展示截图重试及重试耗尽原因。debug 包另有有界异步坏帧取证，保留 alpha 和请求时序，最多八组/32MiB；正式包不启用该 PNG 取证。

本版没有修改 Python 战斗策略、动作优先级或动作后验标准。休闲/排位、有限局数或 `0` 无限、悬浮启停及现有证据管理沿用。画质不限，内容比例设为“原生”，UI 比例调为 1，并使用简体中文界面。
